### **Proyecto: Ampliación de Contenidos Audiovisuales**



**¿De qué trata este proyecto?**



Este proyecto fue desarrollado como parte de la asignatura de Programación Orientada a Objetos. Mi trabajo consistió en ampliar un sistema de contenidos audiovisuales en Java, tomando como base un proyecto proporcionado en clase e incorporando nuevas clases y relaciones entre ellas.



La idea es representar distintos tipos de contenidos audiovisuales y organizar su información mediante el uso de clases y objetos.



**Objetivo**



Aplicar los conceptos de la Programación Orientada a Objetos para ampliar el sistema original, reutilizar código mediante la herencia y representar las relaciones entre los diferentes elementos del proyecto.



**¿Qué incorporé al proyecto?**



Además de las clases originales "ContenidoAudiovisual", "Pelicula", "SerieDeTV" y "Documental", incorporé las siguientes clases:



**Actor**: representa a los actores relacionados con las películas.

**Temporada**: representa las temporadas de una serie de televisión.

**Investigador**: representa a los investigadores relacionados con los documentales.

**VideoMusical**: incorpora un nuevo tipo de contenido audiovisual.

**Cortometraje**: incorpora otra categoría de contenido audiovisual.





trabajé en las relaciones entre las clases y elaboré un diagrama UML para representar visualmente la estructura del sistema.



**Conceptos aplicados**



**Herencia**: permite que "Pelicula", "SerieDeTV", "Documental", "VideoMusical" y "Cortometraje" hereden características de "ContenidoAudiovisual"

**Agregación**: representa la relación entre "Pelicula" y "Actor".

**Composición**: representa la relación entre "SerieDeTV" y "Temporada".

**Asociación**: representa la relación entre "Documental" e "Investigador".



**Herramientas utilizadas**



* Java y Eclipse IDE para desarrollar y ejecutar el proyecto.
* GitHub Desktop y GitHub para gestionar y publicar el código.
* draw.io para elaborar el diagrama UML.



**¿Cómo ejecutar el proyecto?**



**1**. Clonar o descargar este repositorio.

**2**. Importar el proyecto existente en Eclipse.s

**3**. Abrir la clase "PruebaAudioVisual".

**4**. Ejecutar el método "main" para observar los resultados en la consola.



**Aprendizaje y mejoras**



Con este trabajo pude practicar la creación de clases, la organización de atributos y métodos, la herencia y las relaciones entre objetos. También aprendí a representar la estructura del programa mediante UML y a utilizar GitHub para guardar y compartir el código del proyecto.



El proyecto me permitió comprender mejor cómo se pueden ampliar las funcionalidades de un sistema existente aplicando los principios de la Programación Orientada a Objetos.
